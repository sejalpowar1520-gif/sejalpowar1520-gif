## 🚀 Featured Project

### 🛰️ InfraWatch — AI-Powered Urban Safety Platform

**InfraWatch** is a full-stack platform designed to detect potential illegal construction using satellite imagery and AI, then connect those detections to a structured municipal enforcement workflow.

**Highlights**

* 🛰️ Satellite imagery & geospatial mapping
* 🤖 Gemini-powered visual analysis
* 🔍 AI-based violation detection
* 🗺️ Interactive Leaflet maps
* 🚨 Crisis/SLA monitoring workflow
* 👮 Role-based officer management
* 📄 AI-assisted legal notice generation
* 👥 Citizen reporting portal
* 📊 Real-time analytics dashboard
* 🔐 JWT authentication
* 📱 Progressive Web App support

**Tech Stack**

`React` `Vite` `Node.js` `Express` `Gemini AI` `Leaflet` `SQLite` `JWT` `PWA`
